Sunset Surfer

About

The Sunset Surfer set includes a yellow-brown Bugdroid with a surfboarf and wave accessory. The figurine uniquely has magnetic feet to stick to the surfboard. The set also came with an adhesive set for the wave figure.

Hit the waves one last time before a the end of another beautiful day with the Sunset Surfer edition. Our sun-kissed friend comes with board and a special springy desktop wobble wave to ride on!

Each set includes an optional 3M adhesive foot and wave base kit for use in high vibration areas.
