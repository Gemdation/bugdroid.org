Rainbow Set

About

The Rainbow Set contains ten various colorful transparent Bugdroids, nine span across the rainbow while one is a neutral glitter. It was released during Pride month and was sold as a set for...$69.

The case is a half-ways opening box and has artwork of a Bugdroid spewing out a rainbow.
