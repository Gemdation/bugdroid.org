History of Bugdroid.org

This website has had a rich history, starting off in an 'Android Foundry' folder, turned Google Sites, turned definitive GitHub Pages.

Images in this section can be clicked to 'travel' back in time to where this project was.

Starting in June 2021 and abandoned in November 2023, the Android Foundry Fan/Bugdroid Fanpage is the first attempt of Bugdroid merch archive of mine. It had a bit of pages with some having my opinions on each item.

In September 2024, the Android Sanctuary was built off of AFF/BF as the first revision. It has quite more pages.

In a few days, it became the Droid Collection and was suped up with a bit of details and a bit of non-opinionated texts.

In November 2024, Droid Pack was started under droid.gemdation.com. It exited Google Sites to a new pure HTML platform while still having Droid Collection's theme colors based on Material Design 1.

24 days later, Droid Pack fully left Google Sites behind with a new design based on Android's early versions with the brand new dynamic directory header. This version specifically contains an unseen videos page.

In March 2025, Droid Pack became independent with it's new domain at bugdroid.org. By then, it had new directory preview images and a product image viewer that is still used today. Later, the bonus YouTube merch archive directory was made, followed by the Dino and Gemini archives.

As of May 2026, what I call the definitive mark of Bugdroid.org is it's responsive web design, stable CSS, and a huge base of archived products. The Droid Pack name was dropped as Bugdroid.org gives a more contextual name about what the site is, a non-commercial Bugdroid loving site.
